# 数据字典

## 标准化IMU数据表

| 字段 | 含义 |
|---|---|
| `First_Timestamp_ms` | 重建后的墙上时钟时间戳，精确到毫秒 |
| `Timestamp` | 设备内部经过时间，格式为“时:分:秒:毫秒” |
| `R1_Roll`、`R1_Pitch`、`R1_Yaw` | 保留传感器组R1的三个姿态通道 |
| `R2_Roll`、`R2_Pitch`、`R2_Yaw` | 保留传感器组R2的三个姿态通道 |
| `R3_Roll`、`R3_Pitch`、`R3_Yaw` | 保留传感器组R3的三个姿态通道 |
| `R4_Roll`、`R4_Pitch`、`R4_Yaw` | 保留传感器组R4的三个姿态通道 |

已确认的实验布局共使用8个IMU节点，左右各4个，位置分别为腰部、大腿前侧靠近膝盖上方、小腿前侧和脚背。R1–R4是历史转换流程最终保留的4个稳定节点。目前仍缺少保留侧别、R1–R4与具体佩戴位置的对应关系以及角度的物理单位，因此在设备编号或带标签协议提供证据之前，应将这些字段统一表述为通用姿态通道。

## 设备处理后的sEMG数据表

| 字段组 | 含义 |
|---|---|
| `Timestamp` | 记录时间戳；在中间处理数据中统一为墙上时钟毫秒值 |
| `Channel_1` … `Channel_8` | 8路sEMG信号通道 |
| `FP_CH41` … `FP_CH48` | 第一组压力/力信号通道 |
| `FP_CH51` … `FP_CH58` | 第二组压力/力信号通道 |
| `count_foot` / `sum_foot` | 派生的总压力/力数值，不同导出版本命名不同 |

8路sEMG均布置在右侧：`Channel_1–Channel_6`为右大腿环绕区域的6个电极，`Channel_7`位于右小腿前外侧，`Channel_8`位于右脚踝内侧。同一CSV还包含16路足底压力阵列及一个聚合压力值。sEMG通道与身体位置的映射已经确认，但具体肌肉名称以及每个压力传感器的位置仍未确认。

## 实验记录元数据

| 字段 | 含义 |
|---|---|
| participant | 私有受试者标识；公开结果仅使用P01–P06 |
| movement | `tiaogao`表示跳高，`tiaoyuan`表示跳远 |
| session | 私有源文件夹中使用采集开始时间；模型NPZ将其替换为受试者内部的T001等试验编号 |
| modality | IMU、sEMG/力、动作捕捉、跳跃高度或跳跃距离 |

## 质量筛选元数据

| 字段 | 含义 |
|---|---|
| `dataset_rank` | 历史启发式方法生成的排序 |
| `total_score` | 综合启发式得分，不是模型预测概率 |
| `num_cycles` | 用于评分的运动周期数量 |
| `avg_intensity` | 平均运动强度特征 |
| `avg_correlation` | 平均跨模态相关性绝对值 |
| `avg_synchronization` | 峰值时间同步特征 |
