# 模型有效性审查

## 恢复的早期原型做了什么

历史模型脚本读取了6个经过质量筛选的IMU记录，并把文件夹排序`motion_dataset_01`至`06`直接作为类别标签，导致每个记录成为一个独立类别，而不是表示跳高和跳远两类目标动作。随后，脚本：

- 创建了卷积编码器，但没有优化网络权重；
- 使用每个单记录类别计算一个原型；
- 使用建立原型的同一批6个记录进行预测；
- 将这种重代入准确率作为模型性能报告。

该结果只能作为软件流程的概念验证，不能证明跳跃类型识别准确率或跨受试者泛化能力。

## 最低限度的可信评估要求

- 目标标签：跳高与跳远；
- 独立性单位：受试者，而不是窗口；
- 数据划分：留一受试者交叉验证，或至少使用完全独立的测试受试者；
- 预处理统计量只能使用训练受试者拟合；
- 报告每折样本数、平衡准确率、Macro-F1、灵敏度/特异度和混淆矩阵；
- 对比IMU-only、sEMG-only、早期/晚期融合和简单非神经网络基线；
- 使用受试者或会话级Bootstrap置信区间报告不确定性；
- 避免根据训练时使用的质量得分或结果选择测试记录。

由于仅有6名受试者，全部结果都应表述为先导研究。要支持较强的产品或论文结论，仍需更多参与者和重复实验。

## 当前有效证据

首个修正后的六人实验记录在[早期实验结果](../results/PILOT_RESULTS_ZH.md)中：任意1秒窗口下，sEMG统计特征分类为最佳基线，平衡准确率67.8%；双分支CNN为65.6%。足底压力事件中心窗口将IMU+sEMG CNN提高到三个随机种子平均88.8%。

后续正式实验进一步使用IMU独立事件定位、嵌套留一受试者方案和统一模型比较。完整IMU TCN达到90.89% ± 3.50%的平衡准确率；R3+R4精简TCN达到88.56% ± 0.23%；R3+R4紧凑型Transformer达到89.47% ± 1.74%。逐节点重训练显示R4的信息贡献最大，Transformer学习曲线则显示仍存在受早停控制的过拟合倾向。

所有结果仍属于预先分段实验的离线分类，不得表述为已经验证的连续识别、自动外骨骼调参或临床性能。
