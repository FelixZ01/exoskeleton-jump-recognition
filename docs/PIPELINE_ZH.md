# 数据处理流程

```text
多设备采集导出
  ├── 打包IMU串口CSV
  ├── 原始与设备处理后的sEMG CSV
  ├── 力/足底压力通道
  └── 动作捕捉及跳跃距离/高度记录
          │
          ▼
1. IMU解码与时间戳重建
          │
          ▼
2. 按受试者、动作与采集时间匹配实验记录
          │
          ▼
3. 在毫秒公共时间轴上对齐IMU与sEMG
          │
          ▼
4. 关节角缺口插值与质量标记
          │
          ▼
5. 足底压力或IMU事件检测并构建定长跳跃窗口
          │
          ▼
6. 按受试者隔离训练、验证和测试
          │
          ▼
7. 多模型、模态和传感器配置评估
```

## 恢复的历史处理流程

原始脚本采用1毫秒全局间隔。已确认的布局包含8个物理IMU节点，左右各4个，位置分别为腰部、大腿前侧靠近膝盖上方、小腿前侧和脚背。正式采集负载提供8组三值槽位，历史处理将零基索引`[4, 2, 1, 3]`对应的4个稳定传感器组重排为R1–R4的Roll、Pitch和Yaw。结合旧程序中的髋—膝—踝约束、右侧sEMG配置及消融结果，工作映射为R1腰/髋部、R2大腿前侧膝上、R3小腿前侧、R4脚背，且较大概率属于右侧链（中等置信度）。

历史严格对齐原型会裁剪较早开始的模态、根据IMU设备时钟检测缺口、为缺失毫秒插入行，并以sEMG时间轴统一长度。清理后的实现明确建立公共时间轴并记录缺失比例，避免把填充值默认为真实观测。

设备处理后的sEMG表还包含16路足底压力通道以及`sum_foot`或`count_foot`聚合值。数据集构建器可对聚合压力进行平滑、定位低压力腾空阶段，并以事件为中心截取模型窗口。项目也实现了IMU独立事件定位，用于降低推理阶段对足底压力的依赖。除非被明确指定为模型输入，否则压力只用于定位事件，不作为sEMG通道。

## 推荐分析单位

一次实验由受试者、动作类型（`tiaogao`或`tiaoyuan`）和采集时间共同标识。每名受试者只归入训练、验证或测试中的一个集合，避免个体动作和传感器佩戴模式跨集合泄漏。当前训练代码结合类别加权、窗口内标准化、早停、记录级概率聚合和多随机种子重复。

正式评估覆盖传统模型、MiniROCKET、CNN、BiLSTM、TCN和紧凑型Transformer，同时包含模态对比、逐IMU节点重训练消融与精简传感器配置实验。
