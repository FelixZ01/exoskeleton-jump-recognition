# 实验照片中的传感器佩戴证据

![可穿戴传感器正面佩戴图](assets/sensor_setup_front.jpg)

## 照片能够直接支持的结论

仓库所有者确认：使用黑色绑带固定的黑色模块是IMU节点，米色弹性绷带用于固定sEMG电极区域。腿部旁边可见的白色球形物体是动作捕捉反光标记点，不是IMU。外骨骼背负在受试者背部，因此在这张正面照片中不可见。

照片中可以看到8个黑色IMU模块，呈左右对称分布，每侧4个：

| 佩戴位置 | 可见数量 | 照片支持的描述 |
|---|---:|---|
| 腰部 | 2 | 左右腰各1个 |
| 大腿前侧靠近膝盖上方 | 2 | 左右大腿各1个 |
| 小腿前侧 | 2 | 左右小腿各1个 |
| 脚背 | 2 | 左右脚背各1个 |
| **合计** | **8** | 每侧4个，左右对称布置 |

照片与实验回忆共同支持“每侧4个”的配置，因此可以推翻此前缺少证据的“大腿6个、小腿1个、脚踝1个”描述。

## 照片无法确认的内容

照片中看不到可读取的硬件编号或数据槽位标签，因此无法确定每个物理模块对应原始IMU槽位1–8中的哪一个。R1–R4可以明确认定为历史建模保留的4个IMU姿态组，因为每组包含Roll、Pitch和Yaw。“每侧4个”的布局使“模型保留了单侧链”成为合理推测，但仅凭数据和照片仍无法证明4组全部来自同一侧、保留的是哪一侧，也无法确定R1至R4的具体身体位置顺序。

实验回忆表明，完整配置由左右两条“腰部至足部”的4节点链组成，后续建模保留其中4个稳定节点。现有消融实验中R4信息贡献最大，这与R4位于小腿远端或足部的假设相容，但不能构成证明。没有设备编号、线缆记录或带标签的佩戴协议前，不得把具体侧别和R1–R4顺序写成确定事实。

## sEMG位置与解释边界

8路sEMG均布置在右侧，已确认的通道与位置关系如下：

| sEMG通道 | 佩戴位置 |
|---|---|
| `Channel_1–Channel_6` | 右大腿环绕区域的6个电极 |
| `Channel_7` | 右小腿前外侧 |
| `Channel_8` | 右脚踝内侧 |

米色绷带能够显示大致电极固定区域，但没有具体肌肉名称。因此，通道与身体位置的映射已经确认，通道与具体肌肉的映射仍未确认。照片同样不能确定每个足底压力通道的具体位置。

公开照片不包含正脸，并在复制时移除了EXIF元数据。该图片仅用于说明实验设备与传感器佩戴方式，不作为受试者身份信息。
