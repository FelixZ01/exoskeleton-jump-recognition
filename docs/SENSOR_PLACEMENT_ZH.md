# 实验照片中的传感器佩戴证据

![可穿戴传感器正面佩戴图](assets/sensor_setup_front.jpg)

## 照片能够直接支持的结论

数据采集时，我使用黑色绑带固定黑色IMU模块，并用米色弹性绷带固定sEMG电极区域。腿部旁边的白色球形物体是动作捕捉反光标记点，不是IMU。外骨骼由受试者背负，因此没有出现在这张正面照片的视野中。

照片中可以看到8个黑色IMU模块，呈左右对称分布，每侧4个：

| 佩戴位置 | 可见数量 | 照片支持的描述 |
|---|---:|---|
| 腰部 | 2 | 左右腰各1个 |
| 大腿前侧靠近膝盖上方 | 2 | 左右大腿各1个 |
| 小腿前侧 | 2 | 左右小腿各1个 |
| 脚背 | 2 | 左右脚背各1个 |
| **合计** | **8** | 每侧4个，左右对称布置 |

照片与实验回忆共同支持“每侧4个”的配置，因此可以推翻此前缺少证据的“大腿6个、小腿1个、脚踝1个”描述。

## 照片无法确认的内容

采集命名中的`R`表示右侧，编号按身体位置从上到下排列。建模使用的4个节点确定为：**R1右腰/髋部、R2右大腿前侧膝上、R3右小腿前侧、R4右脚背**。历史转换顺序和旧程序中的髋—膝—踝约束与这一命名规则一致。

实验记录显示，完整配置由左右两条“腰部至足部”的4节点链组成，后续建模使用右侧4节点链。R4在消融实验中的信息贡献最大，表明右脚背节点为当前跳跃分类提供了最关键的姿态信息。

## sEMG位置与解释边界

8路sEMG均布置在右侧，已确认的通道与位置关系如下：

| sEMG通道 | 佩戴位置 |
|---|---|
| `Channel_1–Channel_6` | 右大腿环绕区域的6个电极 |
| `Channel_7` | 右小腿前外侧 |
| `Channel_8` | 右脚踝内侧 |

米色绷带能够显示大致电极固定区域，但没有具体肌肉名称。因此，通道与身体位置的映射已经确认，通道与具体肌肉的映射仍未确认。照片同样不能确定每个足底压力通道的具体位置。

公开照片不包含正脸，并在复制时移除了EXIF元数据。该图片仅用于说明实验设备与传感器佩戴方式，不作为受试者身份信息。
